WCUDC V3 DESIGN + FORM BUILDER
==============================
1. Import htdocs/database/schema.sql if setting up a fresh database. The schema now includes the custom form builder tables.
2. If your existing database is already running, import htdocs/database/form_builder_v3.sql once.
3. Service Registration now allows exactly ONE service-team choice. Mobilization is optional and limited to ONE choice.
4. Admin > Form Builder lets super_admin/admin create unlimited custom forms for applications, registrations, surveys, prayer forms, event forms, etc.
5. Published custom forms are available at: /form.php?slug=YOUR-SLUG
6. Admin > Media Manager now shows actual image dimensions and file size. Images are processed to the exact display dimensions for their destination.
7. The homepage and visual system are refined to follow the reference site's structure: premium hero, floating cards, quick-action strip, large editorial sections, scripture banner, gallery, prayer and service call-to-action.
8. Always back up your current database and files before replacing the website.
