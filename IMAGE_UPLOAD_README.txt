Upload logo:
- Open Admin > Images & Logo
- Select "Logo"
- Choose your PNG/JPG/WEBP logo
- Click Upload Image
- The file is automatically saved as logo.<extension>
- The previous logo.* is replaced

Maximum image size: 8 MB.
Allowed: JPG, JPEG, PNG, WEBP, GIF.

If the header still shows the old logo after upload, clear browser cache or use an incognito tab.
